# 培养方案 → 技能映射方法

把用户提供的「专业培养方案」（课程列表 / 培养计划）转化为可写进简历的技能证据，并找出与 JD 的差距。

## 一、为什么要做映射

应届生最大的「资产」是专业课程与课程设计。培养方案里的课程 = 现成的技能证据来源。映射的目的：
1. 把「上过 XX 课」变成「掌握 XX 能力（有课程项目佐证）」。
2. 识别 JD 要求里**已由课程覆盖**的部分 → 写进简历「专业技能 / 教育背景」。
3. 识别 JD 要求里**课程未覆盖**的部分 → 进入学习路线图补强。

## 二、映射步骤

1. **课程归类**：把课程归入能力域。
   - 基础：高数 / 线代 / 概率 / 英语
   - 编程：程序设计 / 数据结构 / 算法
   - 专业核心：按专业（如数据库、操作系统、机器学习、会计学、市场营销…）
   - 实践：课程设计 / 实训 / 毕业设计 / 实习
2. **课程 → 技能**：为每门核心课提取「可展示的能力 + 典型产出」。
   - 例：「数据结构」→ 能用 Python/C++ 实现常见结构与算法，LeetCode 友好。
   - 例：「数据库原理」→ 能设计 ER 图、写 SQL、做简单索引优化。
3. **课程设计 → 项目素材**：把课程设计当作「项目经历」种子，套用 STAR 量化（见 `resume-writing-guide.md`）。
4. **对齐 JD**：把映射出的技能与 `jd-analysis.md` 的清单比对，打标：
   - ✅ 已覆盖（写进简历）
   - 🔶 部分覆盖（写「了解」，路线图补齐）
   - ❌ 未覆盖（路线图核心项）

## 三、培养方案缺失时的处理

- 若用户未提供培养方案：基于专业名称，从常识给出「该专业典型课程 → 技能」的默认映射，并明确标注「默认映射，请以你的真实课表校准」。
- 鼓励用户提供课表 / 成绩单，映射精度会显著提升。

## 四、输出形式

生成一份「技能对照表」嵌入简历工作区（不一定要进最终简历），结构：
```
能力域 | 对应课程 | JD 匹配 | 掌握程度 | 简历落点
```
该表是「简历草稿」与「学习路线图」之间的桥梁。
