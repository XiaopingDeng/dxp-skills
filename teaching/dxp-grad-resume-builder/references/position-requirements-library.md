# 常见岗位典型要求库

当 JD 缺失或模糊时，按目标岗位从此库取「典型要求」作为默认输入（需标注「以实际 JD 为准校准」）。
每条含：硬技能、工具、软技能、常见证书门槛、典型对口专业。

---

## 1. 软件开发工程师（后端 / 前端）
- 硬技能：数据结构与算法、计算机网络、操作系统、数据库、至少一门语言（Java/Go/Python/C++/JS）
- 工具：Git、Linux、MySQL/Redis、Spring/React/Vue、Docker（加分）
- 软技能：问题拆解、文档、协作
- 证书门槛：无硬门槛；算法岗常要求 LeetCode 中等以上
- 对口专业：计算机、软件、信安、电子信息

## 2. 数据分析师
- 硬技能：SQL、Excel、Python/R（pandas/numpy）、统计基础、数据可视化
- 工具：Tableau/Power BI、Hive（加分）、Excel 透视
- 软技能：业务理解、汇报表达
- 证书门槛：无；CDA/CPA 加分
- 对口专业：统计、数学、信管、经济学、工商管理

## 3. 算法工程师（机器学习 / NLP / CV）
- 硬技能：机器学习/深度学习、Python、概率统计、数据结构算法
- 工具：PyTorch/TensorFlow、NumPy/Pandas、Linux、GPU 训练
- 软技能：实验设计、论文复现
- 证书门槛：顶会/竞赛奖（Kaggle、天池）强加分
- 对口专业：人工智能、计算机、统计、自动化

## 4. 产品经理
- 硬技能：需求分析、原型设计、数据分析基础、用户研究
- 工具：Axure/Figma、墨刀、SQL 基础、Excel、Xmind
- 软技能：沟通、同理心、逻辑、优先级判断
- 证书门槛：无
- 对口专业：不限；产品/商科/计算机复合背景有优势

## 5. 运营（用户 / 内容 / 活动）
- 硬技能：内容策划、数据分析（基础 SQL/Excel）、渠道投放基础
- 工具：公众号/抖音后台、Excel、Canva、飞书/企微
- 软技能：创意、执行、复盘
- 证书门槛：无
- 对口专业：不限；新传、市场营销、中文优先

## 6. 财务 / 会计
- 硬技能：会计学、财务管理、税法、Excel 高级（函数/透视）、SAP/用友
- 工具：Excel、财务软件、Power BI（加分）
- 软技能：严谨、细致、合规意识
- 证书门槛：初级会计职称（强相关）、CPA 通过部分科目（强加分）、CET-6
- 对口专业：会计、财管、审计、经济

## 7. 市场营销
- 硬技能：市场调研、品牌、消费者心理、投放（信息流/搜索）
- 工具：Excel、PPT、Canva、巨量引擎/腾讯广告后台
- 软技能：创意、数据敏感度、沟通
- 证书门槛：无
- 对口专业：市场营销、广告、工商管理

## 8. 人力资源（HR）
- 硬技能：招聘流程、劳动法基础、培训/薪酬常识、Excel
- 工具：ATS 系统、Excel、PPT、飞书/企微
- 软技能：沟通、判断、保密意识
- 证书门槛：人力资源管理师（加分）
- 对口专业：人力、心理、工商、社保相关
