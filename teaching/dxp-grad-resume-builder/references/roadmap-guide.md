# 学习路线图撰写方法

路线图是简历的「配套补强计划」：列出简历所需但暂未掌握（或仅初步掌握）的技能，给出可执行的进阶路径。它与简历并列交付。

## 一、路线图定位

- 对象：JD 要求、但用户当前能力（基本信息 + 培养方案映射）未完全覆盖的技能。
- 目标：让用户能按计划真实补齐，把「简历缺口」变成「可达成路径」。
- 语气：务实、可执行、可量化验收，不画大饼。

## 二、每条技能的学习卡结构

对路线图中的**每一项技能**，给出：

```
技能：<名称>
为什么需要：<对应 JD 哪条要求 / 简历哪个缺口>
阶段划分：
  L0 入门（X 周）：目标 + 资源 + 验收
  L1 进阶（X 周）：目标 + 资源 + 验收
  L2 实战（X 周）：目标（做 1 个可写进简历的项目）+ 验收
推荐资源：书籍 / 官方文档 / 课程 / 实战平台（给具体名字）
验收标准：可量化的「学会了」证据（如：独立完成 X、LeetCode X 题、做出 X 项目）
```

## 三、阶段规划原则

- 总周期按「求职倒计时」反推（如 3 个月 / 6 个月），给用户明显里程碑。
- 优先补「必需且缺口大」的技能；「加分项」后置。
- 每阶段必须有**产出物**（代码仓库 / 项目 / 证书 / 笔记），确保能回流进简历。
- 给出每周大致投入时长建议（如 10–15h/周），贴合学生节奏。

## 四、路线图呈现

- 默认产出 `学习路线图_姓名_目标岗位.md`：总览时间线 + 逐技能学习卡。
- 时间线可用分层列表或简易甘特（文本表格）表达阶段与先后依赖。
- 强调「学完即更新简历」，形成「学 → 写 → 投」闭环。

## 五、与简历的呼应

- 简历中标记 `（路线图中补强）` 的技能，必须在路线图里有对应学习卡。
- 路线图末尾给一张「缺口 → 路线图条目」对照表，便于用户核对。
