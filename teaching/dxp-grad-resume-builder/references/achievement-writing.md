# 成果化写法与投递惯例

本文件的两条来源不同，用途也不同：

- **第一、二节**改写自 Tracey Whitmore《How to Write an Impressive CV and Cover Letter: A Comprehensive Guide for Jobseekers》(Robinson, 2021修订版)。可核对的是该书的**目录结构与出版方内容描述**（全书四部分：求职流程 / CV撰写 / LinkedIn档案 / 求职信，附录为 Action words）；**正文页码未核**，引用原书表述时请自行对页码。
- **第三节**是英中投递惯例差异，属行业通行做法，非该书独有。

 Whitmore 面向的是"有工作经验的职场人"（入门至董事会级）。**下面只保留适用于本科生的部分**，其余按`compose-workflow.md` 与 `resume-writing-guide.md` 的应届生规则走——两者冲突时，**应届生规则优先**。

## 一、成果而非职责

Whitmore 的目录里，第 11 章的标题就是 **"Achievements"**，而不是 "Responsibilities"——这个对比本身就是方法论：**写你做到了什么，不是你负责什么**。

对本科生最实用的落点，是**动词强度**。同一件事，动词决定了这条 bullet 是成果还是职责：

| 职责写法（弱） | 成果写法（强） |
|---------------|---------------|
| 负责 / 参与 | 设计 / 实现 / 独立完成 |
| 学习了 / 熟悉了 | 定位 / 复现 / 验证 |
| 协助排查 | 设计分层排查流程并定位到N 例 |
| 整理了测试用例 | 输出 M 条用例，覆盖 K 类工况 |

**判据**：把动词换成"负责"，这条 bullet 立刻变弱，就说明它原本写的是职责。

**弱动词清单**（出现即需改写）：负责、参与、学习、了解、熟悉、整理、梳理、辅助、协助、帮助、跟进。

对实习经历尤其致命——它是唯一的产业经历，却常因"我只是个实习生"写成纯学习记录。改法不是编造产出，而是**把做过的动作落到可数的对象上**：测试了多少块板、整理了多少条用例、复现了几类工况、定位了几例异常。

## 二、三个渠道，一致口径

Whitmore 的核心论点是：CV、求职信、LinkedIn 是你与雇主的**第一轮沟通**，是三个渠道而非一份文件（2021 版把 LinkedIn 单独提成 Part three）。

对本科生的可执行版本：

1. **投同一个岗位，CV 与求职信口径一致**。CV 里写"独立完成 FreeRTOS 移植"，求职信就不能说"参与了嵌入式学习"。
2. **简历只列与该岗位相关的渠道**。投国内岗位不必附 LinkedIn；投外企或外企邮箱投递时，附一个能点开看的 GitHub / 作品集，胜过任何自我评价。
3. **面试口径以 CV 为准**。CV 上每个数字都要能答，答不上来的删掉或补测。

**一岗一版**：同一份简历可以通投，求职信不能——每投一个岗位重写求职信（哪怕只是换了开头为什么这家公司）。

## 三、英中投递惯例差异

UK 与中国简历习惯正面冲突。学生按国内习惯写，投外企时每一条都可能是扣分项。

| 项目 | UK 惯例 | 中国惯例 |
|------|---------|---------|
| **证件照** | 不放。反歧视法规下属无关信息 | 常见，且常被当作加分项 |
| **年龄 / 性别 / 婚否 / 籍贯** | 一律不写 | 国内校招常见字段（政治面貌等） |
| **推荐人** | 写"面试时可提供"，不列姓名电话 | 常列具体人名与电话 |
| **求职意向** | 常省去（由求职信承担） | 常放在页首一行 |
| **篇幅** | 2 页以内；有经验者可到 2 页 | 应届生 1 页即可 |
| **语言** | 仅英文 | 中文简历 + 英文简历两份，出海投递必须另备英文版 |

**指导口径**：先问清投哪里。国内投递保留国内惯例；投 UK / 外企按上表调整。**不要让学生为了"像外国简历"而删掉国内必需字段**——反过来也不要把国内字段带进外企投递。

## 四、从这套规则派生的一份自查清单

写完简历后逐条对照，每条都能答"是/否"：

- [ ] 每条 bullet 的动词换成"负责"后会明显变弱（说明写的是成果）
- [ ] 全文搜不到弱动词（负责/参与/学习/熟悉/整理/梳理/辅助）
- [ ] 每个项目都有起止时间
- [ ] 每个量化数字都能说出测量方法（面试会被追问）
- [ ] 技能分档了，且最强那档挂着最扎实的证据
- [ ] 简历内部无前后不一致（职责声称会的技术，技能栏有对应证据）
- [ ] 每一项"熟练"都能被一个项目或课程佐证
- [ ] 投递方向明确（国内 / 外企），惯例差异已按 `achievement-writing.md` 第三节调整

| 症状 | 成因 | 修法 |
|------|------|------|
| bullet 全是"负责…""参与了…" | 写的是职责不是成果 | 换行动动词 + 落到可数对象 |
| 实习经历读下来像学习日志 | 把实习默认为无产出 | 把动作落到数量上（多少块板、多少条用例） |
| 简历与求职信说法不一致 | 分开写没对齐 | 投同一岗位时以简历为基准对齐 |
| 投外企简历里还有证件照、籍贯 | 照搬国内模板 | 按第三节对照表删减 |
| 技能清一色"熟悉" | 怕显得狂 | 分档，把最弱的放"了解" |
