# 内容库：可复用块 + 改写规则

这一份是「填内容」时查的素材库。**每个块都标了处置等级**，别把所有块都当模板照抄：

| 标记 | 含义 |
|---|---|
| 🟢 **通用** | 与专业、学校无关，可原样复制 |
| 🟡 **换词** | 骨架通用，把专业的课程名/方向名/雇主名替换即可 |
| 🔴 **必重写** | 强依赖口径（学校层次、保研率、地域产业），必须按 `intake.md` 重算 |

---

## 1. 因果链 🟢

> 四年后的 offer ← 大四上学期的秋招 ← 大三下学期的暑期实习 ← 大二大三的项目与竞赛经历 ← 大一大二的基础课

**用法**：行动表写正序（从大一往上垒），讲稿写倒序（从 offer 往回追）。倒序更有冲击力，因为它让新生看到「今天」和「offer」之间只隔了四层。

**挂载点**：行动表每一节结尾都要能回答「这件事挂在这条链的哪一环」。挂不上的一节就删掉。

## 2. 四年主线四阶段 🟡（换阶段名，留结构）

| 阶段 | 通用内涵 | 通用段名 |
|---|---|---|
| 大一 | 数学 + 编程语言地基，把动手变成本能 | 打地基 |
| 大二 | 专业的「内核课」（数据结构、组成原理、操作系统一类） | 补内核 |
| 大三 | 定方向、定路径、拿到实习 | 定方向 |
| 大四 | 秋招变现 + 毕设收网 | 收网 |

**用法**：段名可换（如「筑基 / 破壁 / 定盘 / 收网」），但**必须保持四段**——四段正好对应四个学年，新生能立刻对上号。

## 3. 岗位拆解：招聘市场上没有「XX 工程师」 🟡

**核心断言**：企业不会招一个「物联网工程师」，只会招下面四类人之一。选一层做深，其余保持能对话。

| 方向 | 技能栈（顺序即学习顺序） | 说明 |
|---|---|---|
| 嵌入式软件 / 驱动 | C / C++ → 单片机 → RTOS → Linux 驱动 | 最对口硬件类专业的原生方向 |
| 后端 / 云平台 | Java 或 Go → 数据库 → 微服务 | 岗位最多 |
| 行业方向（专业特色） | 本行业的自控/协议/集成 → 系统集成 | 🔴 名称与内容由 `plan-intake.md` 提取的行业特色词决定 |
| 边缘 AI / 算法 | Python + 数学 → 深度学习 → 端侧部署 | 门槛最高，通常要求读研 |

**「拿不准怎么办」的默认答案**：选**向下兼容**的那一层。
判断方法：问「A 的能力在 B 的岗位上算不算加分」。
- 后端能力在嵌入式岗位上算加分；嵌入式能力在后端岗位上不算 → **拿不准选后端/云平台**。
- 算法岗普遍要求硕士；若不想读研，别把算法当默认。

**但这条默认必须让位给口径。** `intake.md` 第 4 问的答案（学长学姐**实际**去哪）优先级高于本节的通用默认：
- 若口径是「实际去向集中在智能硬件 / 嵌入式 / 工业控制」→ **默认选项改成嵌入式软件 / 驱动**。理由要写出来：本专业的课程链（电路 → 模数电 → 组成原理 → 微控制器 → 嵌入式 OS）就是为这一层铺的，其他专业补不齐这段；且该层向后端迁移的通道敞开，反过来则不通。原「选后端」的论证在校方课程体系偏硬件时应被替换，而不是照抄。
- 若口径是「实际去向集中在中型企业 / 行业集成商」→ 方向卡里强调「项目能演示、能讲清技术选型」，弱化算法题门槛。
- 若口径是「实际去向集中在头部企业」→ 强调算法题、八股、实习经历。

**「拿不准」的答案写在哪**：行动表第四节末尾用一条 `.note` 收口，并把「为什么是这一层」写成一句可复述的话——学生记住的就是这句。

## 4. 竞赛：两条主线 🟢（时间需每年核实）

**铁律**：一个硬件类 + 一个综合类，多则无用。

| 类别 | 赛事 | 通用时间 |
|---|---|---|
| 硬件类 | 全国大学生电子设计竞赛 | 奇数年 8 月全国赛 |
| 硬件类 | 嵌入式芯片与系统设计竞赛 | 1–8 月 |
| 硬件类 | 全国大学生物联网设计竞赛 | 5–8 月 |
| 硬件类 | 蓝桥杯（个人赛，练手用） | 春季 |
| 综合类 | 大学生创新创业训练计划（大创） | 每年 3–5 月申报 |
| 综合类 | 中国国际大学生创新大赛（原互联网+） | 校赛 3–5 月，国赛 10–11 月 |
| 综合类 | 挑战杯 | 两年一届 |
| 综合类 | 全国大学生数学建模竞赛 | 每年 9 月 |
| 综合类 | 计算机设计大赛 / 服务外包 / 华为 ICT / 天梯赛 / ACM | 全年分布 |

**一鱼多吃（必须写进两份交付物）**：
> 同一个项目，让它同时是：课程设计 → 竞赛作品 → 大创结题 → 毕设选题 → 简历项目。
> 四年做三个这样的项目，胜过十五个半成品。

**约束**：所有赛程标注「以当年通知为准」，不要臆造日期。

## 5. 逐学期「验收标准」怎么写 🟢

验收标准必须是**可真可假的断言**。「打好基础」「认真学习」是噪音。

句式：`能用 <工具/语言> 独立完成 <可观察的产物>`
- ✅「能用 C 独立写出 500 行以上的程序」
- ✅「能把一段裸机代码改成 RTOS 多任务」
- ✅「能读懂一篇英文技术文档并复述要点」
- ❌「掌握数据结构」
- ❌「提高动手能力」

## 6. 路径决策：保研 / 考研 / 就业 🔴（保研节整体按保研率重算）

**三条路在同一个学期撞车**（大三下 — 大四上）：保研的夏令营、考研的强化期、就业的暑期实习+秋招，物理上做不完两条。**必须给一个决定死线**（通用写法：大三上学期结束前定方向，大四上开学前定路径）。

**保研一节按保研率分档改写**：

| 口径 | 写法 |
|---|---|
| 保研率 ≥ 20% | 保研是**主选项**：给完整的绩点路线、科研路线、夏令营时间线 |
| 保研率 8%–20% | 保研是**有条件的选项**：给名额换算，给出「排名进入门槛才押注」的判据 |
| **保研率 ≤ 8%** | 保研是**意外而非选项**：算出「60 人只有 3–4 个名额」的画面；给「大二暑假用两年排名初判」的分岔点；判据表加一行「排名落在门槛之后 → 不押注保研」；同时强调**绩点仍要守**（转专业、考研复试、出国都用得上） |

**考研一节的通用骨架**：
- 考什么：政治 100 / 外语 100 / 数学 150 / 专业课 150。
- **占便宜的地方**：找出培养方案里**已覆盖的统考科目**（如计算机类 408 = 数据结构 + 组成原理 + 操作系统 + 计算机网络），点明「你们本来就学，但绝不能靠期末突击过关」。
- 冲突：考研强化期（暑假，每天 8–10 小时）与暑期实习同期。折中方案：考研为主 + 一段远程/短期实习兜底。

**决策判据表**（🔴 门槛数字按口径填）：

| 情形 | 建议 |
|---|---|
| 排名在保研门槛内 | 争取保研，同时按就业标准备项目（两条腿走路） |
| 排名在门槛之外 | 不押注保研，专注考研或就业 |
| 数学好、想读书 | 考研，优先本校本专业 |
| 动手强、不想再读 | 直接就业 |
| 想做算法/研究型岗 | 基本必须读研 |

## 7. 用 AI：六条 🟢

**总纲（一句对立式断言）**：
> 它能替你思考，但不能替你理解。

**三条规矩**：
1. 关掉 AI，你能从零复现吗？——不能，就是没学会。
2. 提出问题比回答问题更值钱。——AI 回答得快，但问题是你提的。
3. 基础，是你使用 AI 的资格证。——没有基础，你无法判断它说的是不是错的。

**怎么用才对**（正面 + 一条「绝对不要」）：
- 读不懂概念：让它用三种类比解释，再出题考你。
- 写代码：让它给脚手架和测试，核心逻辑自己写。
- 调 bug：给它完整报错 + 你的猜想，让它列三个可能原因。
- 复习考试：让它当考官，你答，它批改。
- **绝对不要**：整段复制粘贴交作业。

**可选的深水区（学生层次高时加）**：智能即压缩，结构比细节更重要；从机器学习借三个概念管理自己——数据质量（你输入什么）、目标函数（你在优化什么）、优化方法（你用什么节奏逼近）。

## 8. 自学清单：课程 → 公开课映射 🟢

入口：**csdiy.wiki**。原则：官方文档比任何中文二手教程都准。

| 校内课程 | 对应公开课 |
|---|---|
| C / 程序设计基础 | CS50 |
| 数据结构与算法 | CS61B |
| 计算机组成原理 | CSAPP + Nand2Tetris |
| 操作系统 | 6.S081（xv6） |
| 计算机网络 | CS144 |
| 数据库 | 15-445 |
| 数学（线代/微积分） | MIT 18.06 等 |
| 机器学习 / AI | 李沐《动手学深度学习》 d2l.ai |

**实操三条**：一次只跟一门；每门课必须留下一个作品；不追求学完，一学期吃透一门就够。

**替代方案**：若学生层次偏应用、英文吃力，可换成本地化替代（中国大学 MOOC、B 站系统课），但仍保留「一门跟到底 + 留下作品」两条。

## 9. 避坑（16 条，四列：坑 / 表现 / 代价 / 对策）🟡

**A. 时间类**
| 坑 | 表现 | 代价 | 对策 |
|---|---|---|---|
| 游戏与短视频 | 睡前刷到凌晨 | 白天补觉，一天只剩半天 | 见第 10 节配额协议 |
| 作息崩坏 | 连续两周凌晨两点后睡 | 认知与体力双降 | 设固定熄灯点 |
| 在宿舍假装学习 | 书摊在床上，一晚翻三页 | 自我欺骗，成绩不动 | 宿舍只睡觉，学习去教室/图书馆 |
| 只看不做 | 收藏上百教程，一个没动手 | 虚假的充实感 | 每门课必留一个作品 |

**B. 学业类**
| 坑 | 表现 | 代价 | 对策 |
|---|---|---|---|
| 期末突击 | 只为一周后考试 | 知识留不下来，面试一问就露 | 内核课（数据结构/组成/OS/网络）当日常课 |
| 抄实验报告 | 抄同学的 | 做项目时发现自己完全不会 | 实验自己写，慢也要写 |
| 逃避数学 | 「用不上」 | 卡死考研和算法方向 | 数学是地基，不可退 |
| 英语放荒 | 四级拖到大三 | 六级与考研英语连锁崩 | 大一下过四级，大二下过六级 |

**C. 方向类**
| 坑 | 表现 | 代价 | 对策 |
|---|---|---|---|
| 反复换方向/语言 | 每学期换一门语言学 | 积累每次归零 | 大三上定方向后不再换 |
| 广度虚荣 | 什么都学一点 | 什么都不深 | 一层做深，其余能对话 |
| 只跟课不走项目 | 四年无一个完整作品 | 简历空 | 一鱼多吃 |

**D. 诚信与安全类**
| 坑 | 表现 | 代价 | 对策 |
|---|---|---|---|
| 考试作弊 | 一次侥幸 | 学位/学籍终止 | 不碰 |
| 简历造假 | 夸大经历 | 背景核查即出局 | 只写做过的 |
| 网贷 / 高消费 | 分期买设备 | 债务与家庭风险 | 设备够用即可 |
| 毕设凑合 | 随便挑个题 | 四年唯一的代表作烂尾 | 毕设 = 前面项目的延续 |

## 10. 娱乐配额协议（贴在桌前）🟢

> - 先做后玩：任务没完成，不打开游戏
> - 定额：工作日 1 小时，周末 3 小时
> - 物理隔离：手机不放桌上
> - 宿舍只睡觉
> - 每周日晚复盘 30 分钟

**为什么是「协议」不是「戒断」**：把「不玩游戏」写成硬性禁令，三天就破功。给一个可执行、有额度、有隔离手段的协议，才是能活四年的版本。

## 11. 危险信号（出现任意一条就刹车）🟢

- 连续两周凌晨两点后睡
- 连续两周没写一行自己的代码
- 开始用「反正大家都不学」安慰自己

**自查 8 问（可选，层次高时加）**：本周有没有动手产出？有没有一个新概念彻底搞懂？有没有一次主动提问？有没有推进项目？有没有运动？有没有早睡？有没有读非课本的东西？有没有帮别人解决一个问题？

## 12. 最后一句 + 五条原则 🟢

**收尾断言**：
> 这一行不看「你学过什么」，只看「你做出来过什么」。

**五条不可让步的原则**（行动表第十节，可微调）：
1. 内核课不许糊（数据结构、组成原理、操作系统、计算机网络）。
2. 每门课留下一个作品。
3. 大二结束前必须有一段完整的项目经历。
4. 大三下必须拿到一段实习。
5. 不碰作弊、不碰造假、不碰网贷。

## 13. 高中 vs 大学：三条对照 🟢

| 维度 | 高中 | 大学 |
|---|---|---|
| 知识范围 | 有考纲，边界清楚 | 没有边界 |
| 考查密度 | 周考月考，持续反馈 | 一学期考一次 |
| 驱动方式 | 老师喂到嘴边 | 没人管你 |

**推论**：跟着课堂走，在高中能拿高分，在大学只能拿到及格。
