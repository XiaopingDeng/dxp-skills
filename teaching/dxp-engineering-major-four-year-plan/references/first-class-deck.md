# 第 3 步：开学第一课（飞书演示稿）

产出：`XX专业开学第一课.md` —— 专业主任导入飞书后，用**演示模式**逐页播放。

## 唯一的结构规则

**一个一级标题 `#` = 一页。** 除此之外不用任何标题层级（不用 `##`、`###`）。正文只有三种元素：

- 短句（一行一个断言）
- 无序列表（每页 3~5 项，每项 ≤20 字）
- 加粗（一页最多一处，用来压住那个「必须被记住」的句子）

不用表格、不用代码块、不用引用块、不用嵌套列表——飞书演示模式对这些的渲染不稳定，且会把页面撑高。

## 语气：这是专业主任在讲话，不是在发宣传册

- 第二人称「你们」，全程口语，短句，能读出声。
- **敢讲实话才是可信度的来源。** 「关于保研，我讲句实话」「这个岗位在招聘市场上根本不存在」这类句子要保留——新生听腻了场面话，一句实话能让他记住整堂课。
- 不承诺结果、不喊口号。每一页要么给一个事实，要么给一个动作。
- 数字要具体到出画面感：不写「保研率低」，写「60 人的专业，只有 3–4 个名额」。

## 页序骨架（40 页起，按此顺序）

**开篇（4 页）**：封面（年份 + 专业 + 主讲：专业主任）→ 今天不讲课程表（只讲三件事：路长什么样 / 哪里会摔 / 现在做什么）→ 先看一组数字（家底：学分、实践占比、AI+ 占比）→ 一句话说清培养目标。

**本专业是什么（2 页）**：一个容易被忽略的属性（列出带行业特色的课程名）→ 这条特色是优势不是负担（列出对口雇主圈层）。**注意**：雇主圈层必须落在 `intake.md` 的口径内；学校层次低就写「系统集成商 / 弱电与智能化工程公司 / 地方国企信息化部门」，不要写头部大厂。

**四年全景（4 页）**：四年主线（四段一句话）→ 一条因果链（offer ← 秋招 ← 实习 ← 项目 ← 基础，倒着念）→ 今天做的事三年后才付账 → 四个不能错过的时点。

**逐学期（8 页）**：每学期一页，格式固定为「3~4 门本学期关键课 + 一行课外动作」。课名与学期**逐字抄自培养方案**，是这份讲稿与行动表对齐的地方。大四两页要提到毕设学分和春招兜底。

**规则变化与岗位真相（2~3 页）**：课堂是基线上限靠自学 → 高中与大学规则不一样（知识范围 / 考查密度 / 驱动方式三条对照）→ 招聘市场上没有「XX 工程师」这个岗位（拆成四类）。

**方向与路径（10~12 页）**：四条路各自要什么 → 拿不准的时候（给向下兼容的默认选项）→ 保研说实话（算名额画面）→ 保研靠什么加分 → 保研时间线 → 考研考什么 → 考研占便宜的地方（对照培养方案里已覆盖的统考科目）→ 考研与实习冲突 → 三条路正面冲突（给死线月份）→ 怎么选（决策判据）。

**竞赛（4 页）**：两条主线就够 → 硬件类赛事 → 综合类赛事 → 一条铁律（同一项目做五用）。

**AI 与自学（6 页）**：用 AI 的总纲（一句对立式断言）→ 三条规矩 → 怎么用才对（含「绝对不要」）→ 免费课程入口 → 按课程排的自学清单 → 自学实操三条。

**避坑与收尾（5 页）**：最容易踩的坑（一）→（二）→ 一个协议贴在桌前 → 危险信号 → 最后一句 + 现在开始。

合计约 **45±5 页**。少于此就说明**该加页而不是该往每页塞字**。

## 加页不加班

用户会说「内容太简略」。**正确的响应是加页，不是加字。**

- 一页只承担一个断言。断言之间有转折就拆两页。
- 出现了「（一）（二）」这种分页，说明那组内容本来就该拆。
- 每页正文控制在 **≤6 行**。超出立刻拆页。
- 拆页的信号：出现「另外」「同时」「顺带一提」。

反面教材：把「保研 + 考研 + 就业」压成一页讲完。正确做法是各一页，再加一页「三条路撞车」、一页「怎么选」。

## 与行动表的一致性（交付前逐项核对）

讲稿是行动表的压缩朗读版，不是另一个版本。以下必须在两份文件里**逐字一致**：

- 保研率（及其换算出的名额画面）
- 四个不能错过的时点的年月
- 三条路冲突的死线月份
- 总学分 / 实践占比 / 专业类课程门数 / AI+ 占比
- 每条路线的技能栈顺序、竞赛名称与时间

## 飞书导入提示

- 直接 `docs +create` 导入这份 md 即可；一级标题会被识别成分页。
- 导入后提醒主讲：在飞书文档右上角切到**演示模式**，用方向键翻页。
- 讲稿是讲稿，不是逐字稿——允许主讲在每页基础上自由发挥，所以每页只给骨架句，不写长段。

## 完成判据

- 页数 ≥ 40。
- 每页正文 ≤ 6 行，无表格/代码块/嵌套列表。
- 上列「一致性」清单逐项核对通过。
- 通读一遍，问自己：**如果删掉行动表、只剩这份讲稿，新生还能不能记住「什么时候必须做什么」？** 不能就补页。
