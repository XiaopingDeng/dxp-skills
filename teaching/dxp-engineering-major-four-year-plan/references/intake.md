# 第 0 步：取口径

口径是整份技能的地基。**同一份培养方案，换成二本学校和大厂目标校，两份交付物几乎每一节都要重写。** 所以先问全，再动笔。

## 六个必问项（一次问完，别分轮）

用一条消息发出去，编号列清楚，方便用户逐条回。

| # | 问什么 | 为什么必须是它 |
|---|---|---|
| 1 | **专业名称 + 年级**（如「物联网工程 2026 级」） | 决定文件命名与文件名里的年份 |
| 2 | **学校层次**：985/211/双一流 · 普通一本 · 普通二本 · 民办/高职 | 决定雇主圈层写法、竞赛目标定多高、升学建议的权重 |
| 3 | **保研率**（百分比或名额。没有就给个大概） | 决定「保研」那一节的战略结论——是当计划还是当意外 |
| 4 | **学长学姐实际去哪**（行业 + 企业类型 + 岗位名） | 决定四个技术方向里哪一个放首位。**问"实际去哪"，不问"应该去哪"** |
| 5 | **该专业的行业特色**（培养方案里反复出现的方向词） | 决定「我们的特色」整节。专业名往往不带这个信息 |
| 6 | **学校所在城市 + 当地支柱产业** | 决定实习半径与雇主举例的地理范围 |

## 缺项处理

用户答不全时，**先给区间 + 标注假设，继续往下做，在交付时集中提示核对**。不要卡住等答案。

| 缺项 | 默认取值 | 交付时怎么提示 |
|---|---|---|
| 学校层次 | 按用户对"能不能进大厂"的态度推断；无信号则取「普通一本」 | 「雇主圈层按普通一本口径写，如与实际不符告诉我，我重写第 1 节和第 5 节」 |
| 保研率 | 见下表按层次取 | 「保研率按 X% 假设，请核对教务处推免文件」 |
| 就业去向 | 按专业特色词 + 主干学科推断 | 「雇主举例按 XX 行业写，请按你们实际就业名单校正」 |
| 地域 | 不写具体城市，只写"本地/区域" | 「实习半径未落到具体城市，需要的话我补」 |

## 口径 → 影响的对照表

动笔前把这张表填满，后面每一节都从这里取值。

| 口径 | 影响哪一节 | 怎么变 |
|---|---|---|
| 学校层次 = 双一流/211 及以上 | 竞赛（节 4）、方向（节 5） | 竞赛可以写「冲国奖」；方向里可以放「算法/AI」并提示读研 |
| 学校层次 = 普通一本 | 同上 | 竞赛写「省级打底、国奖争取」；方向首位放行业应用或后端 |
| 学校层次 = 普通二本及以下 | **雇主圈层（节 1、5）**、实习窗口 | 雇主改成"行业集成商、方案商、地方国企信息化部门、中小型厂商"；实习窗口从「3–5 月大厂提前批」放宽到 **3–6 月**，并明说"中小型对口企业集中在 4–6 月" |
| 保研率 ≥ 15% | 保研节 | 写成可争取的目标，给加分杠杆清单和夏令营时间线 |
| 保研率 8%~15% | 保研节 | 写成"有希望但要拼"，加一句初判时点 |
| **保研率 ≤ 8%** | 保研节 | **写成"意外而非选项"**：算出"60 人的专业只有 3–4 个名额"这类具体画面；给「2028 年 7 月用两年排名初判」的分岔时点；决策判据表里加一行"排名落在门槛之后 → 不押注保研" |
| 就业去向集中在中型企业 | 方向节 | 方向卡里强调"项目能演示、能讲清技术选型"，弱化算法题门槛 |
| 就业去向集中在头部企业 | 方向节 | 强调算法题、八股、实习经历 |
| 专业有明确行业特色 | 节 1 首屏、节 5、第一课 | 单列一节讲特色对应的产业带；雇主清单按这条产业带写 |
| 专业无特色（宽口径） | 节 5 | 明确写"本专业没有天然对口行业，所以方向选择更要提前" |

## 顺手问的三件（影响不大但省一轮往返）

1. 你要哪几份交付物？（行动表 / 开学第一课 / 两份都要 / 还要飞书文档）
2. 你是老师还是学生？（决定第一课的口气：老师用第一人称"我讲句实话"，学生用"我跟你说清楚"）
3. 有没有前几届的行动表或宣传材料可以对齐风格？

## 常见坑

- **把"应该去哪"当成"实际去哪"**。用户说"我们专业应该能去海康大华"，这通常是愿景不是事实。追问一句"上一届实际签了哪些单位"。
- **忽略保研率的乘数效应**。6% 和 20% 是两个完全不同的策略，不只是数字不同。
- **不问地域**。同层次学校在长三角和在内地，实习机会差一个量级。
